# Обученные веса финального ансамбля

| Папка | Модель | Вес в ансамбле |
|---|---|---|
| `final_tcn_h128/` | TCN, ширина 128, dropout 0.3 | 2 |
| `final_gru_h128l3/` | GRU, ширина 128, 3 слоя | 1 |
| `final_tcn_h128e60/` | TCN, ширина 128, 60 эпох | 1 |
| `final_gru_h96l3/` | GRU, ширина 96, 3 слоя | 1 |

В каждой папке:
* `final_seed0.pt`, `final_seed1.pt`, `final_seed2.pt` — три запуска с разными seed, обученные на всех 80 записях;
* `glob_norm.npz` — нормировка глобальных признаков по обучающим данным;
* `result_final.json` — параметры обучения (по ним `predict.py` собирает модель).

`src/predict.py` ищет модель сначала в `outputs/<папка>/` (если вы переобучили её через `python reproduce.py final`), потом здесь.
