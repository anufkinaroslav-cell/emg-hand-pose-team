# ЭМГ → углы пальцев · «Научная орбита», StackMoreLayers

Модель восстанавливает положение пальцев (20 углов суставов) по электрической активности мышц предплечья (6 каналов ЭМГ, 500 Гц). Команда «Без dat'ы».

| Решение | Weighted MAE, CV по дням |
|---|---|
| Всегда средняя поза | 0.377 |
| Бейзлайн организаторов | 0.222 |
| Наша первая модель (ансамбль TCN + TCN + GRU) | 0.110 |
| **Финальное решение: ансамбль 4 моделей × 3 seed** | **0.1058** |

Ошибка в радианах, меньше — лучше. Каждая модель проверяется на днях записи, которых не видела при обучении (то же разбиение на 4 фолда, что у организаторов). Подробности: [docs/EXPERIMENTS.md](docs/EXPERIMENTS.md), объяснение метода: [docs/METHODOLOGY.md](docs/METHODOLOGY.md).

**Материалы:** [презентация команды (PDF)](docs/presentation_bez_daty.pdf) · [решение по шагам (PDF)](docs/reshenie_po_shagam.pdf)

## Быстрый старт

**1. Установка** (Python 3.10+):

```bash
pip install -r requirements.txt
```

**2. Данные:** положите данные соревнования в `data/`, как описано в [data/README.md](data/README.md).

**3. Проверка, что данные на месте** (около минуты; должно получиться CV ≈ 0.377 для средней позы):

```bash
python reproduce.py check
```

**4. Прогноз для этапа 2.** Обученные веса финального ансамбля уже лежат в `models/` (4 модели × 3 seed), переобучать не нужно:

```bash
python reproduce.py predict --input-dir test --template data/phase2_sample_submission.csv --output outputs/submission_phase2.csv
```

На CPU это около 5 минут. Чтобы обучить модели заново на всех 80 записях: `python reproduce.py final`. Новые веса появятся в `outputs/` и будут использоваться вместо `models/`.

Для этапа 1: `--input-dir phase1_test --template data/phase1_sample_submission.csv`.

Если `predict` напечатает `WARNING: test EMG std ...`, единицы теста не похожи на обучающие: сначала проверьте данные.

## Полное воспроизведение

| Команда | Что делает | GPU T4 | CPU, 4 ядра |
|---|---|---|---|
| `python reproduce.py check` | данные + базовая линия «средняя поза» | 1 мин | 1 мин |
| `python reproduce.py cv` | CV по дням для 4 моделей (по 3 seed) и ансамбля → ≈ 0.106 | ~50 мин | ~4–5 ч |
| `python reproduce.py sanity` | проверка на утечку: перемешанные ответы → CV ≈ 0.47 (хуже средней позы) | ~4 мин | ~15 мин |
| `python reproduce.py final` | 4 финальные модели на всех данных, по 3 seed | ~25 мин | ~2 ч |
| `python reproduce.py predict ...` | прогноз и CSV для отправки (веса из `models/`) | 1–2 мин | ~5 мин |

* Видеокарта используется автоматически, если она есть (`--device auto`).
* Готовые шаги пропускаются, поэтому после обрыва команду можно просто запустить заново.
* `--smoke` у `cv`, `final`, `sanity` и `predict` — быстрая проверка, что весь конвейер запускается (2 крошечные эпохи, результаты пишутся в папки с суффиксом `_smoke` и ничего не значат).

## Решение кратко

1. **Признаки «громкости» мышц** на 50 Гц: log-RMS в окнах 50–500 мс и в трёх полосах частот, 42 признака на кадр.
2. **Нормализация по записи** (минус медиана записи) убирает сдвиг уровня сигнала между днями. Абсолютная громкость подаётся отдельным входом с шумом при обучении.
3. **Модели видят всю запись:** TCN (дилатированные свёртки) и двунаправленная GRU, плюс общий контекст записи (усреднение по времени).
4. **Вспомогательная задача:** распознавание одного из 8 движений (точность на CV 97–100%).
5. **Функция потерь повторяет метрику** (вес активного пальца 0.5).
6. **Аугментации:** случайные фрагменты 6–12 с, растяжение по времени ×0.8–1.25, шум.
7. **Ансамбль**, подобранный жадным отбором по CV:

   | Модель | Вес | CV одной модели |
   |---|---|---|
   | TCN, ширина 128 | 2 | 0.1081 |
   | GRU, ширина 128, 3 слоя | 1 | 0.1098 |
   | TCN, ширина 128, 60 эпох | 1 | 0.1085 |
   | GRU, ширина 96, 3 слоя | 1 | 0.1096 |

   Каждая модель — среднее 3 seed. Ансамбль: **0.1058**.

## Проверки честности

* **CV только по дням:** сессии одного дня никогда не попадают одновременно в обучение и проверку.
* **Нормализация глобальных признаков** считается только по обучающим дням фолда.
* **Метка движения на вход не подаётся,** она используется только как вспомогательная цель при обучении.
* **Контроль с перемешанными ответами** (`reproduce.py sanity`): каждой обучающей записи даются углы другой записи. Результат: CV 0.472 (хуже средней позы 0.377), распознавание движения 12.5% (случайный уровень). Значит, качество берётся из связи «сигнал → углы», утечки нет.
* **Число эпох фиксировано,** лучшая эпоха по проверке не выбирается.

## Структура

```text
reproduce.py           единая точка входа: check / cv / sanity / final / predict
src/configs.py         состав финального ансамбля и параметры моделей
src/nn.py              признаки → модели (TCN, GRU, Transformer), CV, финальное обучение
src/framefeat.py       признаки ЭМГ на 50 Гц
src/common.py          загрузка данных, фолды по дням, метрика соревнования
src/predict.py         прогноз по сохранённым весам + CSV
src/make_submission.py CSV по образцу организаторов (клип в [-π, π], проверка NaN)
src/ens_cv.py          CV заданного ансамбля по OOF-прогнозам
src/ens_search.py      жадный подбор ансамбля по OOF-прогнозам
baseline/utils.py      код организаторов (разбиение на фолды), MIT, © Ilia Semenkov
docs/                  методика, эксперименты, презентация и решение по шагам (PDF)
models/                обученные веса финального ансамбля (4 модели × 3 seed)
data/                  данные соревнования (не в git, см. data/README.md)
```

Отдельные модели можно запускать напрямую, например:

```bash
cd src && python nn.py --name my_tcn --arch tcn --hidden 128 --dropout 0.3 --seeds 3
```

Все параметры: `python src/nn.py --help`.
